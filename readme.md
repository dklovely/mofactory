## 本软件基于Difflinker和GHP-MOF部分功能修改并创建新的功能 ##

软件地址如下：

Difflinker：https://github.com/igashov/DiffLinker

GHP—MOF：https://github.com/hyunp2/ghp_mof

其中模型训练以及HOF分子生成参考Difflinker

文件碎片化参考GHPMOF

##  Tanimoto：将文件放入datasets，运行similarity.py，输入文件地址，即可在当前文件夹下输出分析结果文件
 
plot_simmilarity用于结果可视化，输入csv文件地址即可生成热图文件  ##

##  SAscore：将需要分析的文件放入当前目录下即可生成结果分析文件，运行sascore_analysis  ##

##  crystalize:根据文件类型修改代码中文件地址，hcb和sql堆积方式需先识别后再输入，即可生成堆积后的cif文件  ##
